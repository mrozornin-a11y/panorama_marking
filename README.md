# Разметка панорам петрографических шлифов

Настольная программа (Windows 11, Python 3.13 + PySide6 + Pillow) для оформления готовых панорам шлифов:
распознавание пар «параллельные / скрещённые николи», масштабные линейки, разметка мест детальной
съёмки окружностями заданного физического диаметра и пакетный экспорт в JPEG.

## Установка и запуск

1. Установите Python 3.13 с python.org (отметьте «Add python.exe to PATH»).
2. Дважды щёлкните `run.bat`.
   При первом запуске создаётся локальное окружение `.venv` и устанавливаются зависимости из
   `requirements.txt` (нужен интернет). Последующие запуски — тем же `run.bat`.

Запуск вручную:

```bat
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

## Работа

1. **Новый проект…** — выберите папку с панорамами (PNG, JPG, JPEG), затем место для файла проекта (`.json`).
   Пары определяются по имени: файл, имя которого оканчивается отдельной буквой `с`/`c`
   (кириллической или латинской, любой регистр), — скрещённые николи; без неё — параллельные.
   Порядковый номер из имени файла сохраняется в названии пары: `16. Г-170`.
   Неполные и неоднозначные пары отмечаются знаком ⚠; исправляются кнопками
   **Назначить файлы…** и **Поменять местами**. **Удалить из списка…** убирает пару из проекта
   (с подтверждением; фотографии на диске не удаляются, остальные пары не перенумеровываются).
2. Режим **Проверка пар**. Колесо мыши — масштаб, средняя кнопка или пробел + левая кнопка —
   перемещение, **Показать целиком** — вписать изображения в окно. Справа — панель проверки:
   - **Размеры изображений** — сравнение разрешений внутри пары (кружок в списке шлифов):
     зелёный — различие до 5 %, жёлтый — 5–15 %, красный — более 15 %. Кроме того, каждое изображение
     сравнивается с медианой всей выборки (по √(ширина × высота)); если оно больше или меньше медианы
     более чем в 1,5 раза, пара подсвечивается жёлтым, даже если внутри пары размеры совпадают.
     Это только диагностика: масштаб автоматически не меняется, DPI не используется.
   - **Совмещение**:
     1. выберите **эталон** — параллельные или скрещённые николи; его геометрия и разрешение не меняются;
     2. поставьте точки 1, 2, 3 на обоих изображениях в одних и тех же местах шлифа (не на одной прямой);
        все шесть точек можно перетаскивать;
     3. нажмите **Совместить** — по трём парам точек рассчитывается аффинное преобразование, и второе
        изображение приводится к координатам и холсту эталона (смещение, поворот, масштаб, растяжение по осям);
     4. **Вернуться к исходным** — показать исходное изображение и поправить точки, затем снова «Совместить»;
        **Сбросить** — удалить точки и вернуть исходное отображение.
     После совмещения окружности ставятся и двигаются на обеих панорамах с одинаковыми координатами
     и диаметрами (Shift — поправка только на одной панораме), оба изображения используют масштаб эталона,
     а при экспорте вместо исходного файла берётся исправленная панорама. Исходные файлы не меняются;
     точки, эталон и преобразование сохраняются в проекте.
   - **Масштаб эталона** — по умолчанию 4632 px = 21 мм и помечен как непроверенный; реальную ширину
     эталона в миллиметрах можно задать в меню «Масштаб эталона».
   - **Требуется пересъёмка** — такие пары по умолчанию пропускаются при «Экспорт всех»
     (при экспорте можно выбрать «Экспортировать все»).
3. Режим **Разметка** — справа появляется панель **Инструменты**: выбор увеличения (или клавиши `1`–`4`),
   щелчок по любой панораме ставит окружность (только контур, без заливки) на обе панорамы — после
   совмещения в те же координаты, иначе по точкам (если расставлены) или по относительным координатам. Режим размещения остаётся активным для следующих щелчков.
   Инструмент **Курсор** (или `Esc`) — выбор и перемещение: щелчок по окружности выделяет её,
   окружности и номера перетаскиваются мышью. Перемещение на одной панораме сразу пропорционально
   повторяется на второй (это одно и то же место шлифа); с зажатым **Shift** окружность или номер
   сдвигается только на одной панораме — для точной подгонки, и эта поправка сохраняется.
   В списке объектов: увеличение, **Цвет окружности** отдельно для параллельных и скрещённых,
   **Указать положение** (в т. ч. для неразмещённых),
   **Показать на панораме** (или двойной щелчок), **Удалить** (`Delete`).
   **Добавить неразмещённый снимок** — объект с номером, но без положения.
   **Цвет всех окружностей шлифа** — отдельно для параллельных и скрещённых: все окружности и номера
   текущего шлифа на этой панораме становятся выбранного цвета (другие шлифы не меняются);
   **Сбросить цвета шлифа** — вернуть цвета по умолчанию.
4. **Настройки** — шрифты и толщины линий (в пикселях изображения с масштабом 4632 px = 21 мм; для
   изображений с другой калибровкой пересчитываются, чтобы физический размер был одинаковым), цвета окружностей
   по умолчанию (параллельные — чёрный, скрещённые — белый), качество JPEG. Настройки общие для всего проекта.
5. **Экспорт текущего** / **Экспорт всех** — для каждого шлифа создаётся папка с тремя файлами:
   `<имя> параллельные.jpg`, `<имя> скрещенные.jpg` (панорама + линейка) и `<имя> схема.jpg`
   (имя с исходным номером, например `16. Г-170/16. Г-170 схема.jpg`)
   (обе панорамы, подписи, линейки, окружности и номера). Экспорт идёт в фоне из исходных файлов
   в полном разрешении; исходные изображения не изменяются.

Горячие клавиши: `1`–`4` — увеличения 2.5×/5×/10×/20×, `Esc`, `Delete`, `Ctrl+S`, `Ctrl+Z`, `Ctrl+Y`.

Проект сохраняется автоматически (через 2 с после изменения, при переключении шлифа и при закрытии).

## Расчёты

- Масштаб: по умолчанию 4632 px = 21 мм; ширину эталона можно задать вручную, после совмещения
  второе изображение получает масштаб эталона.
- Линейка — на узком белом поле под панорамой, у правого края (на 5 px левее края изображения).
  Длина — кратная 5 мм, ближайшая к 30 % ширины панорамы и меньше 50 %; для очень узких
  панорам — 2 или 1 мм.
- Диаметры полей зрения: 2.5× — 7.58 мм, 5× — 4.59 мм, 10× — 2.18 мм, 20× — 1.09 мм.

## Ограничения

- «Сжимать изображения» включено: JPEG с заданным качеством (93); если файл получается больше 20 МБ,
  качество автоматически снижается шагами, но не ниже 85. Число пикселей не уменьшается.
  Выключено: качество 100 без субдискретизации цвета.
- Формат JPEG ограничен 65 500 px по стороне: если две панорамы рядом шире этого предела, схема
  для такого шлифа не создаётся (будет сообщение об ошибке), остальные файлы экспортируются.
- Отмена (`Ctrl+Z`) хранит до 100 действий разметки отдельно для каждого шлифа в пределах сеанса;
  после «Совместить» / «Вернуться к исходным» история отмены этого шлифа очищается.
- Исправленная панорама имеет размер эталона: если эталон намного больше второго изображения,
  экспорт требует соответственно больше памяти и времени.
